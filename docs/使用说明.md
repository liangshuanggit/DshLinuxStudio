# 使用说明

## 安装 APK

本项目生成的是 `arm64-v8a` 架构的 Debug APK。将 APK 传到安卓手机后开启“允许安装未知应用”并安装。首次启动请允许通知权限，否则前台服务无法持续显示运行状态。

## 首次配置

1. 进入 **设置**，填写 DeepSeek API Key。密钥会加密保存在本机。
2. 返回 **工作台**，点击 **1. 安装 Linux 环境**。
   - 下载 Ubuntu 24.04.5 arm64 rootfs（约 29MB）。
   - 下载 Node.js v24.22.3（约 30MB）。
   - 安装 git、curl、python3、build-essential 等基础工具。
3. 点击 **2. 安装 DeepSeek Harness**。
4. 点击 **启动 DSH 服务**。
5. 点击 **打开 DSH 工作台**。

## dsh 工作目录

APP 把手机上的 `Android/data/.../files/mobile-linux/workspace` 映射为 Linux 内的 `/root/workspace`。在 dsh Web UI 中选择该目录作为工作区即可让 Agent 在手机本地读写代码。

## 本地代码开发

可选安装 code-server：

1. 在 **工作台** 页面点击 **安装 code-server**。
2. 安装后点击 **启动代码工作台**。
3. 点击 **打开代码工作台**，即可在 WebView 中使用 VS Code 界面编辑 `/root/workspace` 中的项目。

也可以在 **终端** 页直接输入 Linux 命令，例如：

```bash
cat /etc/os-release
node -v
npm -v
dsh --version
git --version
```

## 常见问题

**Q：为什么只支持 arm64？**  
A：当前 rootfs、Node.js 与 PRoot 二进制均按 arm64 打包。多数 2018 年后的安卓手机都是 arm64。

**Q：安装很慢怎么办？**  
A：首次安装需要下载 rootfs、Node.js 和 npm 包，建议使用 Wi-Fi。下载完成后会做 SHA256 校验，校验失败会重新下载。

**Q：可以装 Python 包或编译 C/C++ 吗？**  
A：可以。Linux 环境内已安装 python3、pip 与 build-essential，可使用 `pip install` 或 `make` 等工具。

**Q：dsh 启动后打不开页面？**  
A：查看工作台底部的运行日志，确认端口未被占用，且 API Key 已在设置页填写。
